# 十四城双周地点核查与发布

每次把本期获接收的所有新增来源卡按城市和卡号列入清单，包括来源无坐标的记录；零新增的城市登记为零。以来源卡号、原始坐标及精度、来源版本和警方通报身份绑定本次核查。沿用上次已经核实且输入未变的证据。两个定时任务共用一次清单和回执。

此前漏配有两个原因。发布接入曾把已有的来源坐标清空。修复接入后，审核又只选了一份预设路口清单，要求来源坐标与地图节点的距离为零，漏掉街道、建筑、站台以及名单以外的路口。

1. 从已接收的源卡生成待核清单。每张卡检查通报对应段落，区分事发、目击、发现、拦查、逃离方向、征集线索范围和警方联系地址。合刊和带锚点的通报须绑定到具体条目。增量发现仍只用指定第三方来源。核实地点时只复用存档或查证相关原始出处和独立地图对象，保留证据版本。
2. 对有位置线索的卡，检查坐标顺序、市界、同名异地、道路、路口、桥梁、建筑和站点等适用对象。记录具体对象和偏移含义。距离为零或街名相同不能替代语义核实；数值有偏移也要继续核对实际对象。不以预先选定的路口或城市代替全量核查。
3. **计入地图统计**须确认本卡所述事件地点、场景角色及来源坐标与独立几何相符，并通过市界检查。同城同一警方通报只取一个主点，还须查已经发布的历史主点。次要地点可作为参照。
4. **仅作地图参照**用于能确认的具名街路、路口、车站、建筑范围或行动地点。注明参照对象及不确定性，标明不计数；不得把所画的一段路当作已知事发路段。**尚无可核实地图位置**须写明本卡具体缺口，例如仅城区代表点、来源无坐标、角色冲突或同名异地。证据暂不可取得须单列，保存本次尝试；不得把尚未检查写成核查完成。无地图点的公告照常进入适用的翻译和公告统计流程。
5. 私有逐卡回执保留来源版本、警方身份、判定理由和支持证据；公开公告仅携带已审核的分类、理由代码、版本摘要及三语地图状态。实际组装月度地图的场景、三语说明、两档月度与年度六边形，随后核对公告清单。新增、删除、遗漏、重复、跨城或版本不符均需复查。汇报须分别列来源卡、可计数、仅参照、未配图以及零新增城市。
6. 正式打包会执行 `scripts/migration/verify_biweekly_locations.py SITE CITY YYYY-MM-DD`，从实际地图资产及三个语言页面核对每张卡。发布后读取 GitHub Pages 对应版本并复核三语显示、地图计数和参照。按唯一发布写者及既有授权发布；原始正文、私有账本和本机路径留在私有工作区。
